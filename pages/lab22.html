📋 Полный список команд

до начала сборки
1 Подготовка системы (установка зависимостей)
sudo apt update sudo apt install -y build-essential binutils rsync wget \ libncurses-dev libelf-dev libssl-dev file cpio unzip bzip2 flex bison
2 Скачивание и распаковка Buildroot
cd ~ wget http://buildroot.org/downloads/buildroot-2024.11.2.tar.gz tar -xf buildroot-2024.11.2.tar.gz cd buildroot-2024.11.2
3 Создание конфигурации (обход ошибки с терминалом)
⚠️ Важно: Если у тебя не открывался make menuconfig из-за маленького терминала, использовался этот способ.
rm -f .config make defconfig # После этой команды система собралась с настройками по умолчанию.
4 Запуск сборки
make
🧠 Дополнительно (если понадобилось)
Если сборка прервалась (экран погас)
cd ~/buildroot-2024.11.2 make
Чтобы сборка не прерывалась (опционально)
nohup make > build.log 2>&1 & tail -f build.log
