⌨️ Основные команды AstraLinux

Базовые команды для работы в терминале AstraLinux — навигация, работа с файлами, просмотр содержимого и права доступа.

📌 Базовые команды для начинающих

1. Навигация по файловой системе

pwd          # показать текущую директорию
ls           # список файлов и папок
ls -la       # подробный список (включая скрытые)
cd /путь     # перейти в директорию
cd ..        # перейти на уровень выше
cd ~         # перейти в домашнюю папку

2. Работа с файлами и папками

touch file.txt        # создать файл
mkdir folder          # создать папку
cp source dest        # копировать
mv source dest        # переместить/переименовать
rm file.txt           # удалить файл
rm -rf folder         # удалить папку рекурсивно

3. Просмотр содержимого файлов

cat file.txt          # показать содержимое
less file.txt         # постраничный просмотр
head -n 10 file.txt   # первые 10 строк
tail -n 10 file.txt   # последние 10 строк

4. Права доступа

chmod 755 script.sh   # изменить права
chown user:group file # изменить владельца
