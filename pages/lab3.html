🌐 Настройка прокси-сервера

Инструкция по настройке прокси для различных инструментов в AstraLinux (и других дистрибутивах Linux).

Прокси-сервер: proxy.novsu.ru:8080

ℹ️ Примечание: Если прокси требует логин и пароль, используйте формат:
http://логин:пароль@proxy.novsu.ru:8080
📦 Для apt (менеджер пакетов)

Откройте файл конфигурации apt:

sudo nano /etc/apt/apt.conf

Пропишите в файле следующие две строки:

Acquire::http::Proxy "http://proxy.novsu.ru:8080/";
Acquire::https::Proxy "https://proxy.novsu.ru:8080/";

Сохраните файл (Ctrl+X, затем Y, затем Enter).

⬇️ Для wget

Пропишите эти команды в терминале (сначала одну, потом вторую):

export http_proxy="http://proxy.novsu.ru:8080"
export https_proxy="https://proxy.novsu.ru:8080"

Важно: Эти переменные действуют только в текущей сессии терминала. Чтобы сделать их постоянными, добавьте эти строки в файл ~/.bashrc.

🔄 Для curl

Используйте ключ -x для указания прокси:

curl -x http://proxy.novsu.ru:8080/ https://example.com

Или настройте через переменные окружения (аналогично wget).

📁 Для git

Настройте прокси глобально для всех репозиториев:

git config --global http.proxy http://proxy.novsu.ru:8080
git config --global https.proxy http://proxy.novsu.ru:8080

Чтобы отключить прокси для git:

git config --global --unset http.proxy
git config --global --unset https.proxy
🦊 Для браузера Firefox

В самом браузере Firefox настройка прокси выполняется в несколько кликов:

  1. Откройте меню Firefox (три полоски ☰ вверху справа) и выберите Настройки.
  2. Прокрутите вниз до раздела Настройки сети и нажмите кнопку Настроить....
  3. В открывшемся окне выберите Ручная настройка сервиса прокси.
  4. В поле HTTP-прокси введите proxy.novsu.ru, а в поле Порт — 8080.
  5. Поставьте галочку Также использовать этот прокси для HTTPS.
  6. Если прокси требует логин и пароль, Firefox будет запрашивать их при первом обращении. Для постоянного хранения можно использовать расширение FoxyProxy.
  7. Нажмите ОК для сохранения.
💡 Совет: Для удобного переключения между прокси и прямым подключением установите расширение FoxyProxy из официального магазина дополнений Firefox.
✅ Проверка работоспособности прокси

Чтобы убедиться, что прокси работает, выполните команду:

curl -x http://proxy.novsu.ru:8080/ https://ya.ru

Или откройте любой сайт в Firefox после настройки прокси.

⚠️ Внимание: Если вы находитесь не в сети университета, прокси proxy.novsu.ru может быть недоступен. В таком случае отключите прокси или используйте другой.
