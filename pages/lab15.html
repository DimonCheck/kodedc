🎨 Создание красивого MOTD (сообщение дня)

Инструкция по созданию красочного приветственного сообщения (MOTD) с разноцветным текстом и отображением времени подключения.

📝 Шаг 1: Открытие файла .profile

С помощью этой команды заходим в файл:

nano ~/.profile
🎨 Шаг 2: Добавление разноцветного текста

В конце файла пишем:

#!/bin/bash RED='\033[0;31m' NC='\033[0m' GREEN='\033[0;32m' YELLOW='\033[1;33m' BLUE='\033[0;34m' echo -e "${RED} Добро пожаловать${NC}" echo -e "${GREEN} Добро пожаловать${NC}" echo -e "${YELLOW} Добро пожаловать${NC}" echo -e "${BLUE} Добро пожаловать${NC}"

Пример того, как это будет выглядеть:

🔴 Добро пожаловать 🟢 Добро пожаловать 🟡 Добро пожаловать 🔵 Добро пожаловать
✅ Теперь мы сделали разноцветный текст!
⏰ Шаг 3: Отображение времени и даты подключения

Добавляем в файл код для отображения времени подключения:

echo -e "${YELLOW} ___________________ ${NC}" echo " " echo -e "${YELLOW} Время и дата:${NC}" echo " " echo $(date +%T) echo $(date +%Y-%m-%d) echo " " echo -e "${YELLOW} ___________________ ${NC}"
💡 Пояснение команд:
• date +%T — отображает текущее время в формате ЧЧ:ММ:СС
• date +%Y-%m-%d — отображает текущую дату в формате ГГГГ-ММ-ДД
📜 Шаг 4: Полный готовый скрипт

Весь код, который нужно добавить в файл ~/.profile:

#!/bin/bash RED='\033[0;31m' NC='\033[0m' GREEN='\033[0;32m' YELLOW='\033[1;33m' BLUE='\033[0;34m' echo -e "${RED} Добро пожаловать${NC}" echo -e "${GREEN} Добро пожаловать${NC}" echo -e "${YELLOW} Добро пожаловать${NC}" echo -e "${BLUE} Добро пожаловать${NC}" echo -e "${YELLOW} ___________________ ${NC}" echo " " echo -e "${YELLOW} Время и дата:${NC}" echo " " echo $(date +%T) echo $(date +%Y-%m-%d) echo " " echo -e "${YELLOW} ___________________ ${NC}"
✅ Шаг 5: Активация и проверка

Сохраните файл: Ctrl+X → Y → Enter

Чтобы активировать скрипт без перезагрузки, выполните:

source ~/.profile

или

. ~/.profile

Или просто перезайдите в систему (logout и login).

✅ Наш скрипт готов! Осталось только активировать и проверить.
🎨 Цветовая схема ANSI
