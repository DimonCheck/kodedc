🛡️ Первичная защита сервера

Допустим, вы купили новый сервер. Прежде всего его нужно «защитить». Вот полный список действий.

💡 Важно: Если работа делается на виртуальной машине, то лучше сначала установить один адаптер — NAT.
📊 1. Проверка входов и логов SSH
journalctl -u ssh

Показывает все логи службы SSH.

journalctl -u ssh | grep Accepted

Показывает только успешные входы по SSH.

last

История последних входов пользователей в систему.

🔑 2. Работа с паролями и обновлениями

Создать свой новый пароль:

sudo passwd

Изменить пароль пользователя.

Обновить список пакетов и установить обновления системы:

sudo apt update && sudo apt upgrade -y
👤 3. Создание нового пользователя
sudo useradd -m USERNAME
sudo passwd USERNAME
sudo usermod -aG sudo USERNAME
sudo usermod -s /bin/bash USERNAME
su - USERNAME

(если надо зайти в нового юзера, exit если выйти)

💡 Примечание: Если вы всё таки делаете это с виртуальной машины, то пока у вас NAT кроме всего этого надо скачать iptables-persistent и fail2ban.
📦 4. Установка iptables-persistent
sudo apt install -y iptables-persistent

🔄 5. Замена NAT на intnet (внутренняя сеть)

Теперь заменяем NAT на intnet (внутренняя сеть) и делаем следующие пункты.

🔐 6. SSH-ключи (вход без пароля)

Настроить SSH на клиенте.

На сервере:

Создать SSH-ключ на ПК:

mkdir ~/.ssh

Создать папку для SSH-ключей:

touch ~/.ssh/authorized_keys

Создать файл для публичных ключей:

chmod 700 ~/.ssh

Ограничить доступ к папке SSH:

chmod 600 ~/.ssh/authorized_keys

Ограничить доступ к ключам.

🧱 7. Базовый Firewall (iptables)

Если скачен iptables-persistent, пишем правила:

sudo iptables -A INPUT -i lo -j ACCEPT
sudo iptables -A INPUT -m conntrack --ctstate RELATED,ESTABLISHED -j ACCEPT
sudo iptables -A INPUT -p icmp -j ACCEPT
sudo iptables -A INPUT -p tcp -m tcp --dport 22 -j ACCEPT
sudo iptables -P INPUT DROP
sudo iptables -P OUTPUT ACCEPT
sudo iptables -P FORWARD ACCEPT
🛡️ 8. Защита от брутфорса (Fail2Ban)
sudo nano /etc/fail2ban/fail.local

В этот файл вставляем базовую конфигурацию:

[DEFAULT] # Игнорируем локальный компьютер, чтобы случайно не заблокировать себя. # Вместо "IP" вставьте реальный IP-адрес, который нужно исключить из блокировок. # Несколько адресов указываются через пробел, например: 127.0.0.1 192.168.1.100 ignoreip = 127.0.0.1/8 # Время блокировки в секундах. 1h = 3600 секунд. bantime = 1h # Время, за которое считаются попытки (1 час). findtime = 1h # Количество неудачных попыток до блокировки. maxretry = 5 # Включаем защиту для SSH. [sshd] enabled = true port = ssh filter = sshd logpath = /var/log/auth.log

Перезапускаем fail2ban:

sudo systemctl restart fail2ban.service

Проверяем статус защиты SSH:

sudo fail2ban-client status sshd
✅ Защита сервера настроена!
