💬 Переписка между компьютерами с помощью nc (Netcat)

Инструкция по организации текстовой переписки между двумя компьютерами с использованием утилиты Netcat (nc).

⚠️ ВАЖНО:
• Если вы переписываетесь между виртуальными машинами — используйте ВНУТРЕННЮЮ СЕТЬ.
• Если переписываетесь между другими компьютерами — используйте СЕТЕВОЙ МОСТ.
🖥️ Шаг 1: Настройка на первом компьютере (сервер)

Пишем это на первом компьютере (1488 — это личный порт для переписки):

nc -u -l -p 1488

Ключи:

  • -u — использовать UDP протокол
  • -l — режим прослушивания (listen)
  • -p 1488 — порт для прослушивания
💡 Примечание: Порт 1488 можно заменить на любой другой свободный порт (например, 8080, 7777, 9000).
🖥️ Шаг 2: Подключение со второго компьютера (клиент)

На втором компьютере пишем команду, указывая IP первого компьютера и тот же порт:

nc -u (ip первого компьютера) 1488

Например, если IP первого компьютера 192.168.5.2:

nc -u 192.168.5.2 1488
💬 Шаг 3: Обмен сообщениями

Теперь можно обмениваться сообщениями:

  • Печатайте текст в терминале на любом из компьютеров
  • Текст будет появляться на другом компьютере
  • Так работает двусторонний чат через Netcat
✅ Переписка работает! Сообщения отправляются мгновенно.
💡 Как выйти из nc: Нажмите Ctrl+C для завершения соединения.
📝 Дополнительная информация

Если нужно использовать TCP вместо UDP:

nc -l -p 1488
nc (ip первого компьютера) 1488

Для отправки файлов через nc:

На принимающей стороне:

nc -l -p 1488 > received_file.txt

На отправляющей стороне:

nc (ip принимающей стороны) 1488 < file_to_send.txt

Узнать свой IP-адрес:

ip addr
