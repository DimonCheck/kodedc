📁 Отправка файлов в переписке между компьютерами с помощью nc

Инструкция по отправке текстовых файлов между двумя компьютерами с использованием утилиты Netcat (nc).

💡 Примечание: Создать нормальные IP, если не знаете как, читать статьи выше.
🖥️ Шаг 1: Подготовка на первом компьютере (принимающая сторона)

Прописать эту команду в одном из компьютеров, предварительно убедиться, что текстовый файл существует (polka.txt). ЕСЛИ НЕТ, ТО СОЗДАТЬ ЕГО.

Как создать файл polka.txt:

touch polka.txt

или

nano polka.txt

(написать текст и сохранить Ctrl+X → Y → Enter)

Команда для приема файла (знак >):

nc -u -l -p 5353 > polka.txt

Ключи:

  • -u — использовать UDP протокол
  • -l — режим прослушивания (listen)
  • -p 5353 — порт для прослушивания
  • > polka.txt — перенаправление вывода в файл
🖥️ Шаг 2: Отправка со второго компьютера (отправляющая сторона)

На другом компьютере создать текстовый файл nc.txt для пересылки и отправить:

Как создать файл nc.txt:

echo "Привет, это тестовое сообщение" > nc.txt

или

nano nc.txt

Команда для отправки файла:

cat nc.txt | nc -u 192.168.5.2 5353

Ключи:

  • cat nc.txt — читает содержимое файла
  • | — передает вывод в следующую команду
  • nc -u 192.168.5.2 5353 — отправляет данные на первый компьютер
🔄 Шаг 3: Если сразу не отправилось

Если сразу не отправилось, повторить операцию, поменяв знак с (больше) на (меньше) на первом компьютере:

nc -u -l -p 5353 < polka.txt
✅ Все должно сработать!
💡 Объяснение:
• > — перенаправление вывода (запись в файл)
• < — перенаправление ввода (чтение из файла)
В зависимости от версии nc может потребоваться использовать один из этих вариантов.
✅ Шаг 4: Проверка результата

На первом компьютере проверьте содержимое принятого файла:

cat polka.txt

Вы должны увидеть текст, который был отправлен со второго компьютера.

📝 Альтернативный вариант (TCP)

Если UDP не работает, попробуйте TCP (без ключа -u):

На первом компьютере:

nc -l -p 5353 > polka.txt

На втором компьютере:

cat nc.txt | nc 192.168.5.2 5353
