🚪 Настройка Knockd (port knocking)

Инструкция по настройке Knockd — системы "стучания" по портам для скрытого открытия доступа к SSH.

🖥️ Шаг 1: Предварительная настройка VirtualBox

Создаем первую виртуальную машину — СЕРВЕР:

  • Адаптер 1 — NAT (для доступа в интернет)
  • Адаптер 2 — Внутренняя сеть (internal network)
🌐 Шаг 2: Установка IP на eth1
sudo ip a a 192.168.5.1/24 dev eth1
ip -c a
📦 Шаг 3: Установка knockd
sudo apt update

Добавляем прокси если нужен, например:

curl -O -x proxy.novsu.ru:8080 http://ftp.de.debian.org/debian/pool/main/k/knockd/knockd_0.7-1+b1_amd64.deb
ls
sudo dpkg -i knockd_0.7-1+b1_amd64.deb
sudo apt search libpcap0.8
sudo apt install libpcap0.8
sudo apt install knockd
⚙️ Шаг 4: Настройка knockd.conf

Заменяем в этом файле -A на -I:

sudo nano /etc/knockd.conf

В строке command = /sbin/iptables -A INPUT -s %IP% -p tcp --dport 22 -j ACCEPT заменяем -A на -I:

command = /sbin/iptables -I INPUT -s %IP% -p tcp --dport 22 -j ACCEPT

И после строчки UseSyslog пишем это:

interface=eth1
🔧 Шаг 5: Настройка sshd_config
sudo nano /etc/ssh/sshd_config

Разкомментируем строчку #Port 22 и пишем свой порт (оставляем 22 пока).

⚙️ Шаг 6: Настройка /etc/default/knockd
sudo nano /etc/default/knockd

В этой строчке 0 заменяем на 1:

START_KNOCKD=1

И раскомментируем эту строчку KNOCKD_OPTS="-i eth1" (также можно исправить eth1 на нужный интерфейс).

🚀 Шаг 7: Запуск knockd
sudo systemctl status knockd
sudo systemctl start knockd
sudo systemctl enable knockd
sudo systemctl status knockd
🔥 Шаг 8: Настройка iptables
sudo iptables -L --line-numbers

Если выглядит вот так, значит все нормально, просто не заполнено:

Chain INPUT (policy ACCEPT) num target prot opt source destination Chain FORWARD (policy ACCEPT) num target prot opt source destination Chain OUTPUT (policy ACCEPT) num target prot opt source destination

Пишем первое правило:

sudo iptables -A INPUT -m conntrack --ctstate ESTABLISHED,RELATED -j ACCEPT

Проверяем его наличие (оно должно появиться):

sudo iptables -L --line-numbers

Пишем второе правило:

sudo iptables -A INPUT -p tcp --dport 52 -j REJECT

Проверяем его наличие (оно должно появиться):

sudo iptables -L --line-numbers
💾 Шаг 9: Установка iptables-persistent
sudo apt install -y iptables-persistent
curl -O http://ftp.de.debian.org/debian/pool/main/i/iptables-persistent/iptables-persistent_1.0.23_all.deb
ls
sudo dpkg -i iptables-persistent_1.0.23_all.deb
sudo apt search netfilter-persistent
curl -O http://ftp.de.debian.org/debian/pool/main/i/iptables-persistent/netfilter-persistent_1.0.23_all.deb
ls
sudo dpkg -i netfilter-persistent_1.0.23_all.deb
sudo dpkg -i iptables-persistent_1.0.23_all.deb
sudo service netfilter-persistent save
🖥️ Шаг 10: Создание второй ВМ (клиент)

Создаем вторую ВМ (клиент) с внутренней сетью.

Настраиваем и устанавливаем IP и пингуем сервер:

ip -c a
sudo ip a a 192.168.5.2/24 dev eth0
ping 192.168.5.1
🔑 Шаг 11: Стучимся (port knocking)

Стучимся на порты:

for port in 7000 8000 9000; do nc -zvn 127.0.0.1 $port; done

или

nc -zvn 192.168.5.1 7000 8000 9000

Пробуем подключиться по SSH на порт 52:

ssh astra@192.168.5.1 -p 52
💡 Не получается через 52, зато войдешь через 22.
🔄 Шаг 12: Меняем местами (22 ↔ 52)

Теперь сделаем так чтобы было наоборот: войти через 52, а через 22 не войти.

Заменяем 22 на 52 в knockd.conf:

sudo nano /etc/knockd.conf

Заменяем Port 22 на Port 52 в sshd_config:

sudo nano /etc/ssh/sshd_config

Перезапускаем службы:

sudo systemctl restart sshd
sudo systemctl restart knockd
✅ Теперь все должно заработать! Вход только через порт 52 после стука.
