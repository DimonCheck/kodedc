📡 NETSTAT, SS, LSOF, NMAP — мониторинг сети и портов

Инструкция по использованию команд для мониторинга сетевых подключений, прослушиваемых портов и диагностики сети в Linux.

📊 NETSTAT

Утилита для отображения сетевых подключений, таблиц маршрутизации, статистики интерфейсов.

Установка:

sudo apt install net-tools

Основные команды:

netstat -tulpan

Ключи:
-t — TCP порты
-u — UDP порты
-l — только прослушиваемые порты
-p — показать программу, которая слушает порт
-a — все порты
-n — показывать IP и порты числом (без DNS-имён)

Поиск конкретного порта (например, 631 — CUPS печать):

netstat -tulpan | grep 631
🔍 SS

Современная замена netstat (работает быстрее и показывает больше информации).

Установка:

sudo apt install ss
ss обычно уже установлен в большинстве дистрибутивов Linux.

Основные команды:

ss -tunl

Ключи:
-t — TCP порты
-u — UDP порты
-n — показывать IP и порты числом
-l — только прослушиваемые порты

С нумерацией строк:

sudo ss -tunl | nl
📂 LSOF (List Open Files)

Показывает список открытых файлов и процессов, включая сетевые сокеты.

Установка:

sudo apt install lsof

Показать все сетевые подключения:

sudo lsof -i

📝 Практический пример: смена порта Apache2

1. Редактируем конфигурационный файл Apache2:

sudo nano /etc/apache2/ports.conf

Меняем порт с 80 на другой, например 2026.

Было: Listen 80
Стало: Listen 2026

2. Сохраняем файл (Ctrl+X → Y → Enter)

3. Перезапускаем Apache2:

sudo systemctl restart apache2

4. Проверяем, что порт 80 больше не прослушивается:

sudo lsof -i :80

Эта команда ничего не выведет — порт 80 больше не прослушивается Apache2.

5. Проверяем, что порт 2026 прослушивается:

sudo lsof -i :2026
🗺️ NMAP (Network Mapper)

Мощный сканер портов и сетевой анализатор.

Установка:

sudo apt install nmap

Основные команды:

Сканирование TCP, UDP и определение версий сервисов:

sudo nmap -sT -sU -sV 192.168.5.2

Ключи:
-sT — TCP сканирование
-sU — UDP сканирование
-sV — определение версий сервисов

Сканирование портов с 1 по 100:

sudo nmap -p1-100 10.0.2.15

Сканирование портов с 1 по 50000:

sudo nmap -p1-50000 10.0.2.15

📝 Практический пример: создание прослушки порта через netcat (nc)

1. Создаём прослушку порта 8080 на сервере:

sudo nc -l 8080

2. В другом окне терминала сканируем порты снова:

sudo nmap -p1-50000 10.0.2.15
✅ После этой команды мы увидим, что добавился порт 8080!
💡 Примечание: nc -l 8080 создаёт прослушивающий сокет на порту 8080. NMAP при сканировании обнаружит этот открытый порт.
📋 Краткая шпаргалка
Команда Описание
netstat -tulpan Все прослушиваемые порты с программами
ss -tunl Аналог netstat (быстрее)
sudo lsof -i Все сетевые подключения
sudo lsof -i :порт Кто слушает конкретный порт
sudo nmap -sV IP Сканирование портов и версий сервисов
sudo nmap -p1-100 IP Сканирование диапазона портов
nc -l порт Создать прослушку порта
