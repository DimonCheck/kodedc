🔑 PuTTY, подключение без пароля

Инструкция по настройке PuTTY и PuTTYgen для входа на виртуальную машину по SSH без ввода логина и пароля.

📥 Шаг 1: Установка PuTTY

Если PuTTY нет на устройстве, его надо скачать.

Скачать можно с официального сайта: https://www.putty.org/

🖥️ Шаг 2: Подготовка виртуальной машины

Перед началом работы нужно:

  • Запустить виртуальную машину
  • Установить сеть (сетевой мост)
  • Обновить MAC-адрес
  • Узнать свой IP командой:
    ip -c a
💡 Желательно скопировать IP-адрес.
⚙️ Шаг 3: Настройка PuTTY

После этого в поиске набрать PuTTY и нажать на него. Появится небольшое окошко PuTTY Configuration.

  • В поле Host Name вставить свой IP-адрес
  • Порт по умолчанию оставить 22
  • В поле Saved Sessions тоже вставить свой IP
  • Нажать Save справа ниже

Нажимаем на свой IP. Потом нажимаем Open. Появится новое окно.

Нужно будет нажать Connect Once и ввести логин и пароль от виртуальной машины, например:

login: astra
Password: astra
✅ Мы вошли в виртуальную машину!

Но наша задача — войти без ввода логина и пароля.

🔐 Шаг 4: Генерация ключей в PuTTYgen

Для этого нужно в поиске набрать PuTTYgen и нажать Generate.

⚠️ ВАЖНО: ВО ВРЕМЯ ГЕНЕРАЦИИ НУЖНО ШЕВЕЛИТЬ КУРСОРОМ МЫШИ В ОКНЕ ДЛЯ ЗАГРУЗКИ СЛУЧАЙНЫХ ДАННЫХ.

После этого нажимаем Save private key и сохраняем в удобном месте.

🖥️ Шаг 5: Настройка на виртуальной машине

Возвращаемся в машину и создаем папку .ssh, если не создана:

mkdir .ssh | ls -la

Создали и убедились в ее наличии.

Теперь установим ей права:

chmod 700 .ssh/

Переходим в папку .ssh и создадим там файл:

cd .ssh
touch authorized_keys
chmod 600 authorized_keys

Потом пишем эту команду:

cat >> authorized_keys << EOF

потом копируем туда ключ, который мы сгенерировали ранее (нажать Enter) и пишем:

EOF

Проверяем, что ключ сохранился:

cat authorized_keys
⚙️ Шаг 6: Настройка PuTTY для использования ключа

Теперь наш ключ нужно сохранить в PuTTY.

Заходим в PuTTY:

  • Выбираем наш IP и нажимаем Load
  • Слева выбираем SSH → Auth → Credentials
  • В строке Private key file for authentication: нажимаем Browse... справа
  • Вставляем наш сохраненный в удобном месте ключ
💡 Не торопитесь нажимать Open! Вернитесь и нажмите Save, чтобы сохранить сессию.
✅ Теперь можно входить без пароля!
🚀 Шаг 7: Вход без логина (опционально)

Чтобы не вводить логин, нужно в поле Host Name добавить логин@ перед IP:

astra@192.168.x.x
✅ Теперь можно входить, не вводя пароль и логин!
