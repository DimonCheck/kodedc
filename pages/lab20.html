🌐 Установка и настройка Apache2

Инструкция по установке, настройке и управлению веб-сервером Apache2.

📦 Шаг 1: Обновление системы
sudo apt update
sudo apt upgrade -y
📥 Шаг 2: Установка Apache2

Сначала скачаем его:

sudo apt install apache2 -y
🚀 Шаг 3: Запуск Apache2
sudo systemctl start apache2
⚙️ Шаг 4: Автозагрузка при старте системы
sudo systemctl enable apache2
✅ Шаг 5: Проверка статуса
sudo systemctl status apache2
✅ Если active (running) — значит работает.
✏️ Шаг 6: Редактирование index.html

Перемещаемся в эту директорию:

cd /var/www/html

В этом файле можем редактировать код:

sudo nano index.html
💡 Примечание: Если код Apache2 редактировать не нужно, то возвращаемся в старую директорию:
cd ~
📝 Шаг 7: Полезные команды

Настройка файрвола (UFW):

# Разрешить HTTP (порт 80)
sudo ufw allow 80/tcp
# Разрешить HTTPS (порт 443) - опционально
sudo ufw allow 443/tcp
# Перезагрузить UFW
sudo ufw reload

Управление Apache2:

# Остановить Apache
sudo systemctl stop apache2
# Перезапустить Apache
sudo systemctl restart apache2
# Перезагрузить конфигурацию без остановки
sudo systemctl reload apache2

Просмотр логов в реальном времени:

sudo tail -f /var/log/apache2/error.log
sudo tail -f /var/log/apache2/access.log

Создать конфигурацию сайта:

sudo nano /etc/apache2/sites-available/example.conf
