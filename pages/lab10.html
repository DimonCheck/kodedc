📦 iptables-persistent и установка программ через прокси

Инструкция по установке iptables-persistent для сохранения правил iptables после перезагрузки, а также по установке программ SL, BEAV и других через прокси.

🔒 iptables-persistent (сохранение правил iptables)

Установка iptables-persistent:

sudo apt install -y iptables-persistent

Скачивание deb-пакетов вручную (если нужно):

curl -O http://ftp.de.debian.org/debian/pool/main/i/iptables-persistent/iptables-persistent_1.0.23_all.deb
ls
sudo dpkg -i iptables-persistent_1.0.23_all.deb

Поиск пакета netfilter-persistent:

sudo apt search netfilter-persistent

Скачивание и установка netfilter-persistent:

curl -O http://ftp.de.debian.org/debian/pool/main/i/iptables-persistent/netfilter-persistent_1.0.23_all.deb
ls
sudo dpkg -i netfilter-persistent_1.0.23_all.deb
sudo dpkg -i iptables-persistent_1.0.23_all.deb

Сохранение текущих правил iptables:

sudo service netfilter-persistent save
💡 Примечание: iptables-persistent сохраняет правила iptables в файлы:
/etc/iptables/rules.v4 — для IPv4
/etc/iptables/rules.v6 — для IPv6
После перезагрузки правила восстанавливаются автоматически.
🚂 Steam Locomotive (SL)

Настройка прокси для терминала:

export http_proxy="http://proxy.novsu.ru:8080"
export https_proxy="https://proxy.novsu.ru:8080"

Настройка прокси для apt:

sudo nano /etc/apt/apt.conf

Прописываем эти две строки:

Acquire::http::Proxy "http://proxy.novsu.ru:8080/";
Acquire::https::Proxy "https://proxy.novsu.ru:8080/";

Прописываем репозиторий:

sudo nano /etc/apt/sources.list

Пишем это:

deb [trusted=yes] http://archive.debian.org/debian stretch main contrib non-free

Обновляем список пакетов (выдаст ошибку):

sudo apt update -o

Пишем это (игнорируем проверку даты):

sudo apt update -o Acquire::Check-Valid-Until=false
sudo apt update

Скачиваем sl:

sudo apt install sl
✅ Все должно скачаться!
