📦 Первый этап: минималистичный образ

Собран собственный Linux-дистрибутив на базе Buildroot 2024.11.2 без графического интерфейса. Готовый загрузочный образ disk.img (~200 МБ) проверен в QEMU и VirtualBox.

🧩 Что внутри образа

🐧 Ядро Linux

Версия 6.1.100, собрано с нуля под x86_64.

📦 BusyBox

Базовый набор команд: ls, cp, mv, cat, ps и ещё ~300.

🖥️ GRUB 2

Загрузчик, установленный на FAT/ext2 раздел.

🔐 Вход в систему

Логин: root, пароль: root.

🚀 Как запустить образ в QEMU

Быстрая проверка без VirtualBox и без флешки — прямо в терминале Astra.

cd ~/buildroot-2024.11.2 qemu-system-x86_64 -hda disk.img -m 512 # Если QEMU не установлен: sudo apt update sudo apt install qemu-system-x86
✅ Успех: если появилось приглашение login: — образ работает.
🛠️ Алгоритм исправления ошибок

В процессе сборки почти всегда возникают ошибки. Главное — не паниковать и действовать по одному и тому же алгоритму:

  • Прочитай последние 5–10 строк в терминале. Там почти всегда прямо написано, чего не хватает.
  • Останови сборку (Ctrl+C), если она зависла.
  • Определи тип проблемы:
    • Файл не скачивается → скачай вручную и положи в output/downloads/.
    • Не хватает утилиты (flex, bison, rsync) → установи через sudo apt install.
    • Ошибка конфигурации → исправь через make menuconfig.
  • Запусти сборку снова: make BR2_JLEVEL=1.
  • Повторяй цикл, пока сборка не завершится.
💡 Важно: Buildroot никогда не начинает с нуля. Всё, что уже собрано, сохраняется. После Ctrl+C и повторного make сборка продолжится с того же места.
⚠️ Частые ошибки, которые были
  • Зависание на скачивании (wget, 0%, eta 24h) — скачать файл вручную и положить в output/downloads/.
  • “command not found: flex / bison” — установить: sudo apt install flex bison.
  • “Incorrect selection of kernel headers” — в make menuconfig → Toolchain → Kernel Headers выбрать 6.1.x.
  • “grub-install: встраивание невозможно” — пересоздать образ с разделами через fdisk и создать ext2 для boot.
Совет: все скачанные вручную файлы складывай в output/downloads/ — Buildroot сам их подхватит и не будет качать заново.
