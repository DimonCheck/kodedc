🏷️ Как переименовать hostname

Инструкция по изменению имени виртуальной машины (hostname) в AstraLinux.

📋 Шаг 1: Проверяем текущее имя машины

Напишите в терминале команду:

hostname

Вы увидите текущее имя машины, например:

orel-vanilla-gui

✏️ Шаг 2: Изменяем имя машины

Чтобы переименовать машину (например, в SERVER), выполните команду:

sudo hostnamectl set-hostname SERVER

Примечание: Вместо SERVER вы можете указать любое желаемое имя.

🔄 Шаг 3: Перезагружаем виртуальную машину

После изменения hostname необходимо перезагрузить машину. Для этого:

  • Зайдите в меню «Завершение работы» (в графическом интерфейсе или через терминал)
  • Выберите «Перезагрузка»

Или выполните команду в терминале:

sudo reboot

✅ Шаг 4: Проверяем новое имя

После перезагрузки снова выполните команду:

hostname

Теперь должно отображаться новое имя — SERVER (или то, которое вы задали).

💡 Дополнительная информация:
Команда hostnamectl set-hostname изменяет имя машины сразу в нескольких местах:
  • /etc/hostname — основной файл с именем хоста
  • /etc/hosts — файл сопоставления IP-адресов и имён
Именно поэтому перезагрузка помогает применить изменения корректно.
