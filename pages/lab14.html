🔐 Подключение по SSH без пароля (SSH-ключи)

Инструкция по настройке SSH-ключей для входа на сервер без использования пароля.

🖥️ Шаг 1: Создание машин и настройка IP

Создаем машину клиент и даем ей IP 192.168.5.2.

Клонируем и даем IP 192.168.5.1 (СЕРВЕР).

Настраиваем сеть и Ping — пингуем их.

📁 Шаг 2: Создание папки .ssh на СЕРВЕРЕ

НА СЕРВЕРЕ создаем папку .ssh:

mkdir .ssh | ls .ssh
🔑 Шаг 3: Генерация SSH-ключа на КЛИЕНТЕ

НА КЛИЕНТЕ:

ssh-keygen

Нажимаем Enter (стандартное расположение файла).

Пароль (личный) — можно не делать. Нажимаем Enter и еще раз Enter.

✅ Если появилась картиночка (ключ) — радуемся! Это секретный ключ.
📤 Шаг 4: Копирование ключа на сервер

Потом пишем эту команду:

ssh-copy-id -i .ssh/id_rsa.pub astra@192.168.5.1

Ключ установлен.

Вводим пароль пользователя astra (нажимаем Enter).

✅ Ключ добавлен! Теперь можно заходить без использования пароля.
🚀 Шаг 5: Подключение к серверу без пароля

Пишем в терминале (эта команда нужна, чтобы заходить на сервер):

ssh astra@192.168.5.1
✅ Зашли без пароля!

Проверяем IP сервера:

ip -c a

Если IP сервера отображается нормально (192.168.5.1) — все работает.

Выходим с сервера:

exit
💡 Примечание: Если имя пользователя на сервере отличается от "astra", замените его на нужное (например, user@192.168.5.1).
